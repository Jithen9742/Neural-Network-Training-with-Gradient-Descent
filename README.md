This project demonstrates a simple **neural network training process** using a **single-layer perceptron** and **gradient descent** for weight optimization. The model predicts an output (`ypred`) based on two input values (`x1`, `x2`) and randomly initialized weights (`w1`, `w2`). It minimizes the error using **Mean Squared Error (MSE)** and updates the weights iteratively through **backpropagation**. The training process runs for multiple epochs, reducing the error progressively. The results are visualized using **Matplotlib**, showing the error trend and how the predicted output approaches the actual value. This project highlights key concepts in **machine learning**, such as optimization, weight adjustment, and data visualization, using **Python, NumPy, and Matplotlib**.
